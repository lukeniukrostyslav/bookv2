## Important correction

The earlier project target of 80,000–95,000 words was a planning target, not verified manuscript volume. This report establishes the actual current count from the canonical manuscript files.

The line-edit checkpoint does not change this fact: the existing B11 line-edit files are editorial checkpoint notes, while the canonical manuscript chapter files remain the actual prose source for this count.

## Decision

Do not treat the 95% project progress as 95% publication readiness. B11 can be complete as an editing gate, while the manuscript still requires substantial expansion before it can meet the planned commercial-length target.

B12 remains the next audit gate, but manuscript-length expansion must be addressed in the subsequent production plan rather than hidden inside the word-count figure.
