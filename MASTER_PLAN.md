# MASTER PLAN

## Objective
Create an original, professionally structured commercial novel with strong reader appeal, coherent characters, controlled mystery, emotional stakes, memorable atmosphere, and a satisfying ending.

## Production sequence
B0 Foundation
→ B1 Market / genre research
→ B2 Core concept
→ B3 Story promise / hook
→ B4 World and atmosphere
→ B5 Characters
→ B6 Central mystery / conflict
→ B7 Plot architecture
→ B8 Chapter blueprint
→ B9 Manuscript
→ B9X Full-length manuscript expansion
→ B10 Developmental edit
→ B11 Line edit
→ B12 Continuity / clue / fair-play audit
→ B13 Final manuscript
→ B14 Publication package

## Quality gates
A block is not 100% until its required artifacts exist and have been checked.
The final novel must pass:
- originality check
- continuity check
- character-arc check
- pacing check
- clue/fair-play check
- ending/payoff check
- prose/editing check
- formatting check
